Вся диагностика живёт в свёрнутом Advanced. Отмена асинхронна — после клика Cancel идёт транзитная фаза Cancelling (кнопка дизейблится, «finishing current task…»), затем Cancelled; фаза исполнения берётся из серверного статуса job, не из локальной догадки.

06 /

Память настроек

Последние значения рабочих привычек сохраняются для пользователя этого компьютера: settings аддона лежат в %appdata% (локальный профиль ОС; на macOS — ~/Library/Application Support, на Linux — ~/.config) — не в аккаунте и не в .blend. На другой машине — свой набор; на сервер ничего не синхронизируется. Логика — три корзины: сохранять личные преференции, выводить факты сцены из Blender, сбрасывать транзиент и проверки.

Связь и вход (bridge)

Аддон (Python) общается с OmnibusCloud (.NET) через локальный бридж. Связь поднимается и лечится автоматически; ручной Reconnect — контекстный, как блокеры. Вход — гейт перед Ready: connecting → (bridge down · not found) → signed out → signed in → Ready.

Lifecycle: бридж стартует lazy — при первом показе N-панели (PID Blender передаётся бриджу), не на register(); гаснет через watchdog по parent-PID в самом бридже — при выходе, kill и краше; Windows Job Object / Linux PR_SET_PDEATHSIG — доп. гарантия ОС. Нормальный выход — graceful-shutdown; один инстанс на Blender; смерть бриджа в сессии → авто-релонч; idle-shutdown после долгой невидимости панели. Refresh не нужен — хартбит делает tag_redraw при смене фазы; ручной Reconnect — только контекстно в блокере.

08 /

Принципы редизайна

Что держит всю систему вместе.

AДве поверхности

Поток художника (90%) и диагностика (10%, свёрнута) — физически разные секции.

BОдно действие

Render сам делает upload → validate → preflight → submit. Ручные шаги — в Advanced.

CОдна строка статуса

Один статус и один блокер. У блокера всегда кнопка-фикс: Save scene, Switch to Animation, Switch format.

DПрогрессивное раскрытие

Tiled (split) и Video раскрывают свои параметры только когда выбраны. Дефолт — минимум строк.

EФазовая модель

Состояние = явная фаза (Ready → Running → Completed), а не россыпь булевых флагов.

FБренд как акцент

Lime — точечно, идентичность — в одну строку. Никакого баннера-постера в рабочем UI.

Карта режимов: Still = Image · одна машина  ·  Tiled Still = Image · split  ·  Frames = Animation · sequence  ·  Video = Animation · video
